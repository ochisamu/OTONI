# 接続とデータ

OTONIは信頼する自分の端末で使う個人向けアプリです。生成・閲覧・削除をユーザーごとに権限制御する機能はありません。LANへ公開すると、そのLANから利用できる人がライブラリや生成機能へアクセスできる前提で運用してください。デフォルトはlocalhostです。

音声生成はローカルです。Codex入力支援・アルバム構成・参考情報調査・ジャケット生成はネット接続を使用し、入力した文章をCodexへ送ります。モデル初回取得はHugging Faceなどの公式配布先へ接続します。YouTube投稿は明示的な接続設定と投稿操作が必要です。

- `.env` はローカル設定。公開するのは値の入っていない `.env.example` のみ。
- CodexとHugging Faceの認証情報はそれぞれのCLIが管理します。プロジェクトにコピーしません。
- Google設定・トークン・再開URLはデータディレクトリの `private-youtube/` に保存されます。データ全体を公開しないでください。
- `data/`、`models/`、`work/`、仮想環境、キャッシュ、試聴資料はGitと公開用出力から除外します。
- 過去にトークンをチャットや公開ログへ貼った場合は、該当サービスで失効・再発行してください。

不具合報告では秘密情報を削除した短いエラーだけを共有してください。生の認証応答や生成フォルダの一括添付は不要です。

YouTubeに接続する

動画のダウンロードとYouTube Studioでの公開には、この設定は不要です。アプリから直接投稿する場合に設定してください。

  1. Google Cloud Consoleでプロジェクトを作り、YouTube Data API v3を有効にします。
  2. Google Auth Platformで同意画面を設定します。テスト中は、YouTubeチャンネルを持つ自分のGoogleアカウントをテストユーザーに追加します。
  3. OAuthクライアントを「ウェブアプリケーション」で作成します。
  4. 承認済みのリダイレクトURIに http://localhost:7860/api/youtube/callback を追加し、クライアントのJSONをダウンロードします。
  5. このPCの OTONI → アルバム → 動画・YouTube投稿からJSONを読み込み、「GoogleでYouTubeに接続」を押します。接続先のチャンネルを確認してください。
  6. 動画を書き出し、タイトル・説明文・子ども向け設定・公開範囲を確認して投稿します。

認証設定とトークンはこのPCだけに保存します。チャンネル確認用の読み取り権限と動画アップロード権限を使用します。接続解除はアプリ内から行えます。

LAN上のスマートフォンでは動画のダウンロードができます。Googleへの接続と直接投稿は、アプリを動かしているPCのlocalhost画面で行います。

公開範囲について

未監査のAPIプロジェクト経由のアップロードは、公開を指定してもYouTube側で非公開に制限されます。制限の解除にはGoogleのAPI監査が必要です。画面ではAPIが返した実際の公開範囲を表示します。監査前に公開したい場合は、書き出した動画をYouTube Studioからアップロードしてください。

Google公式：動画投稿と非公開制限 · Google公式：OAuth接続 · YouTube推奨エンコード

テスト状態のOAuth接続は期限切れになる場合があります。その場合は接続し直してください。直接投稿済み動画の編集・削除はYouTube Studioで行います。アプリ内のアルバム名やジャケットの変更は、投稿済み動画を変更しません。
